USDT payments for merchants

pay.mntad.com gives your store crypto addresses, watches the chains for you, and tells your server about every confirmed payment with a signed webhook. What you receive becomes your gateway balance.

  • USDT
  • TRC20 (Tron)
  • BEP20 (BNB Smart Chain)
Read the API docs

Flow 1 · Checkout

Create a payment intent for an exact amount. You get a fresh address and an expiry time.

  • The status moves from waiting, to processing, to paid.
  • Late, partial and extra payments are all handled.
  • No payment is lost.

Payment intents →

Flow 2 · Permanent address

Give each customer one address for life, for wallets and top-ups.

  • Asking again returns the same address.
  • Customers can send any amount, at any time.
  • You get one event per deposit.

Permanent addresses →

Signed webhooks

Every event is signed with HMAC-SHA256 and retried for up to a day.

  • Verify the signature.
  • Re-fetch the deposit before you credit it.
  • Credit each deposit once.
